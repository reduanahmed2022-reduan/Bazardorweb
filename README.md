# 🛒 BazarDor | বাজার দর

### Essential Market Prices of Bangladesh at a Glance

## 📖 About the Project

BazarDor is a responsive web application that helps users explore the prices of essential daily products in Bangladesh. Users can browse products by category, compare price changes, view product details, and manage their profiles through a simple and user-friendly interface.

## ✨ Key Features

1. **Product Price Display:** View prices of essential daily products.
2. **Category-Based Browsing:** Browse products by categories such as rice, lentils, oil, vegetables, and protein.
3. **Price Change Indicators:** Identify products with increasing or decreasing prices.
4. **Product Details:** View detailed information about individual products.
5. **User Authentication:** Register and sign in using email and password.
6. **Profile Management:** View and update user profile information.
7. **Responsive Design:** Browse the website on mobile, tablet, and desktop devices.
8. **Loading Skeletons:** Display loading placeholders while product data is loading.
9. **Toast Notifications:** Receive feedback for authentication and other user actions.
10. **Social Authentication:** Sign in using Google or GitHub, if configured and working.

## ⚙️ Getting Started

### Prerequisites

- Node.js
- npm
- MongoDB connection, if required by the application

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd YOUR_PROJECT_FOLDER
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env.local` file in the root directory and add the environment variables required by your application.

```env
BETTER_AUTH_SECRET=
BETTER_AUTH_URL=http://localhost:3000
BETTER_AUTH_MONGODB_URL=
NEXT_PUBLIC_APP_URL=http://localhost:3000
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
GITHUB_CLIENT_ID=
GITHUB_CLIENT_SECRET=
```

Add the appropriate values locally. Never commit real secrets or database credentials to GitHub.

**5. Start the development server**

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
